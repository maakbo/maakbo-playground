# AGENTS

## Purpose

This repository is a playground for exploring ideas through small experiments.

## Principles

- Keep it simple
- Prefer Markdown
- Document findings
- Work in small steps
- Prefer exploration over perfection
- Good enough is enough

## Outputs

Use simple files such as:

- Markdown notes
- Experiment logs
- Diagrams
- Small prototypes
- Setup guides

## Repository style

Avoid over-engineering.
Keep directory structures lightweight.
When adding an experiment, include a short README or log.
