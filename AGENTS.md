# AGENTS

## Purpose

This repository is an AI playground for exploring ideas through small Markdown-first experiments.

## Principles

- Keep it simple
- Prefer Markdown
- Document findings
- Work in small steps
- Prefer exploration over perfection
- Good enough is enough

## Default workflow

1. Read the nearest README or log first.
2. Make the smallest useful change.
3. Leave a short note about what changed or what was learned.
4. Prefer a rough experiment log over a polished framework.

## Outputs

Use simple files such as:

- Markdown notes
- Experiment logs
- Diagrams
- Small prototypes
- Setup guides

## Repository style

Avoid over-engineering.
Keep directory structures lightweight.
When adding an experiment, include a short README or log.

Do not add heavy tooling, complex templates, or deep folder structures unless the experiment clearly needs them.

## Writing style

- Japanese or English are both fine
- Short notes are welcome
- Bullet points are enough
- Prefer concrete findings over abstract plans
