## 証拠の読み方

- **O / official**：AWS公式の公開情報。開催回を超えて数値設定を保証するものではない。
- **P / participant**：参加者本人の記事。実体験の一次報告であり公式ルールではない。
- **D / community data**：コミュニティ公開の過去大会データ。再構成・未確認値を含み得る。
- **C / community implementation**：公開練習環境のソースで確認した動作。本番のソースではない。
- **H / hypothesis、E / experiment**：この調査から提案する仮説・実験。大会での実証済み攻略ではない。
